Run the bench in your browser

The model runs on this device and no data leaves it. GGUF files run through wllama, on WebGPU when the browser has it and on the CPU otherwise. WebLLM models need WebGPU. The rules match lvwb, and the result file can be submitted like a terminal run. The browser is much slower than lvwb, so start with the quick profile.

wllama (MIT) and WebLLM (Apache-2.0) are loaded from jsDelivr when you press Run. Downloaded models are cached by the browser.
